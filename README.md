# Moss Computer

One HTML file. Inline CSS and a small interactive app preview. No dependencies or build step.

Open `index.html`, or serve this directory:

```sh
python3 -m http.server 8000
```

Publish this directory on any static host, then point `mosscomputer.com` at that host using its DNS instructions. Enable HTTPS. DNS alone does not host the page.

The site says “In development” until the app has a download link and a final price.
